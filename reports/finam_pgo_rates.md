## Формат XLS

Файл отчёта ЕДП (единая денежная позиция) содержит актуальные ставки риска
для клиентов с подключённой услугой «Пониженное ГО».

Листы с ПОНИЖЕННЫМ ГО (снижение уже применено к базовым ставкам):
- `Фьючерсы ФОРТС с пониженным ГО`
- `Ценные бумаги с пониженным ГО`
- `Валюты с пониженным ГО`

Каждый лист содержит 3 колонки для трёх уровней риска:
| Cols | Уровень |
|:----:|:--------|
| 0-7  | КПУР (повышенный) |
| 9-16 | **КСУР** (стандартный) |
| 18-25| КНУР (начальный) |

## Как читать XLS

```python
import openpyxl
wb = openpyxl.load_workbook('file.xlsx', data_only=True)
ws = wb['Фьючерсы ФОРТС с пониженным ГО']

# Si-9.26 starts at row ~45  
for row in ws.iter_rows(min_row=7, values_only=True):
    name = str(row[0])
    if 'Si-9.26' in name:
        ksur_start = float(row[9])   # КСУР начальная
        ksur_min   = float(row[11])  # КСУР минимальная  
        knur_start = float(row[18])  # КНУР начальная
        knur_min   = float(row[20])  # КНУР минимальная
```

## Структура колонок

Row offset 0 = Инструмент с ПГО
Row offset 1 = Код Базового актива  
Row offset 2 = Единая начальная ставка риска уменьшения стоимости
Row offset 3 = Единая начальная ставка риска увеличения стоимости
Row offset 4 = Начальная ставка резерва уменьшения
Row offset 5 = Начальная ставка резерва увеличения
Row offset 6 = Валюта ставки риска
Row offset 7 = Примечание (КВАЛ и т.д.)
Row offset 8 = пусто (разделитель)
Row offset 9 = КСУР: Единая начальная ставка ...
...
Row offset 18 = КНУР: Единая начальная ставка ...
