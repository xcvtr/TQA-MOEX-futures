## 🎯 Новая стратегия: RETEST (портирована из TQA-crypto)

**Паттерн «Возврат к проторговке» (H1):**
1. Проторговка 24 H1 баров: касания >=2/2, slope < 0.05%, ширина 0.5-8%
2. Импульс N >= 0.5%
3. Затормаживание 6 баров (пик подтверждён)
4. Лимитка = peak - 0.15*N (SHORT) / trough + 0.15*N (LONG)
5. TP = H (проторговка), SL = peak*1.003, timeout 48 H1

**Аудит retest:** Top5 51-67% (vs IR 90%+), лучший месяц 16-31% — стабильный эдж
