## 🔴 Баги, найденные аудитом

### Баг 1: Пирамидинг завышал ROI в ~7 раз
- **Где:** `scripts/oi_v12_rolling_v2.py`, `scripts/oi_v12_rolling.py`, `scripts/oi_v12_rolling_margin.py`
- **Что:** `pnl *= n_parts` — умножение ВСЕГО pnl на число частей пирамиды **по цене входа**
- **Эффект:** 2-я и 3-я части пирамиды входили «бесплатно» по цене 1-й (+0.5%/+1.0% не платились)
- **Результат:** CAGR 693-1189% → артефакт. Честный: **330-440%**
- **Фикс:** части пирамиды хранят реальные цены входа (hi+ms / lo−ms), pnl считается по каждой части

### Баг 2: Мой «честный» аудит был БЕЗ компаунда
- **Где:** мои инлайн-скрипты аудита (не в репо)
- **Что:** генерация сделок и симуляция разделены → лоты от фикс eq=200K
- **Результат:** CAGR 96.8% — занижен. Правильный (компаунд на лету): **330-440%**

### Баг 3: Cash MDD 32% в тесте без лимитов
- С лимитами (50-100 контрактов) + маржа 80%: **Cash MDD 5-13%, MTM 13-17%**

## ✅ Live-деплой (исправления в strategies/common/paper_trader.py)

| Изменение | Было | Стало |
|-----------|------|-------|
| fetch_day_net формула | мгновенный (b−s)/(b+s) — НЕ та метрика | **накопление за день** (cur−day_start)/total_oi — как бэктест |
| граница дня | today() = 00:00 IRK | **irk_day = (ts−7h)//86400** = 15:00 IRK, как бэктест |
| окно запроса | 40ч (обрезало день) | **72ч** |
| выход | только timeout 24 мин | **по ОИ**: day_net ≥ exit_thr (long) / ≤ −exit_thr (short) |
| timeout | 24 бара | **max_hold_h=120ч** (age_sec > 120×3600) |
| slippage выход | close без тика | **close − 1 тик** (long), +1 тик (short) |
| пирамидинг | НЕ было | **+1 лот при +0.5%** движения (pyra_max = max_positions−1) |
| лимиты | глобально 20 | **per-ticker**: BR/NG 100, SV 80, RI 50, TT 30 |
| направление | long_only | **contrarian (LONG+SHORT)** |

### Проверка: live = бэктест
- `fetch_day_net('BR')` = **−0.618%** = бэктест-формула **−0.618%** ✓
- Компиляция OK, dry-run OK (`Eq=200000₽, Открыто=0`)
