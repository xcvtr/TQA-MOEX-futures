## 4. 🔍 Найденные проблемы (критично для аудита)

1. **Backtester dayofweek ≠ M1-скрипт**: Backtester (mt5_continuous) даёт 44-86 сделок,
   M1-скрипт (ALLFUT* M1, 63) — 188. Причины:
   - mt5_continuous до 2026 — только вечерняя сессия (ночные бары 00:00-02:00)
   - detect "первый бар дня" ловит ночной бар 00:00 → вход по ночной цене (нереалистично)
   - Backtester тикает по 5-мин close, M1-скрипт — по open 10:00 + trailing по минуткам
   - Фикс ночи добавлен (now_utc.hour < 7 → skip), но Backtester всё равно даёт 44 сделки
2. **OI MTM DD = 7.83%** (из summary и equity_curve.drawdown) — корректно.
   НО equity_curve из bt_oi_framework использует data_source='bars' (moex.bars),
   а portfolio_mix — mt5_continuous. Цифры несопоставимы между прогонами!
3. **Портфель считался за 1 год** (2025-08→2026-08) — компаунд за 1 год может завышать
   (как с OI: 1000%/год артефакт на малом капитале). Нужен полный 2023-2026 OOS.
