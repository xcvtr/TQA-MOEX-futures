# Checkpoint 211: OI + подтверждение стаканом (oi_dom)

- **5-сек вспышки z>8 ask (покупки) → WR 62-70%** (EU, 2.5 года)

## 🧠 Логика oi_dom

```
OI: физ продают (contrarian) → long
+ Стакан: ask-heavy (покупки манипуляторов, imb > 0.1) → ПОДТВЕРЖДЕНИЕ
Иначе → нет сигнала (ложный OI)
```

Направление: юрики-манипуляторы покупают (ask-вспышки) → цена растёт.

## 🐛 Баги/находки сессии

1. **Направление edge = класс актива**: сырьё = contrarian (физ толпа), валюта = momentum (физ умные)
2. **Per-ticker thr**: Eu нужен thr=2% (не 3%), акции — thr=1-3%
3. **RN ослаб** (corr -0.01 в 2025-26), но полезен в портфеле (диверсификация)
4. **Eu прямой edge подтверждён** (fiz momentum, corr +0.23 в 2021) — как помнил пользователь
5. **dom_min1.imbalance = 0** (мёртвая колонка) — считать из сырого dom
6. **Бэкфилл Eu 2019-2023** загружен в mt5_continuous (1M баров)
7. **tick_vol = заглушки** в бэкфилльных данных (vol=5)
