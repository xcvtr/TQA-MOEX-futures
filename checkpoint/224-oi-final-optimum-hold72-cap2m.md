# Checkpoint 224 — Финальный оптимум OI: hold 72ч + кап 2M

## Контекст

Сессия: подгонка стратегии OI (BR/NG/SV) под **MTM DD ≤ 20%** с максимальным
компаундом и пирамидингом. Цель пользователя: 1000%/год за последний год (2026).
Продолжение чекпойнта 223 (полный аудит + ПГО + айсберг).

## 🔍 Ключевые находки сессии

### 1. Баг пирамидинга в бэктесте (add_lots = весь размер!)
```python
# БЫЛО (баг): add_lots = pos['lots'] — при каждой добавке лоты УДВАИВАЛИСЬ
# СТАЛО:     add_lots = pos.get('base_lots', pos['lots']) — базовый размер
```
Эффект бага: avg_entry улетал (SV max_gap +560%!), стопы и MTM DD завышены.
Папер (paper_trader.py:742) ВСЕГДА использовал base_contracts — бэктест расходился с live.

### 2. MTM DD — по close (как папер), НЕ по lo/hi
Папер `calc_mtm_equity` считает MTM по **close бара** (bd['prc']), а бэктест по lo/hi →
DD завышен внутридневными хвостами. Исправлено: MTM по close в бэктесте.

### 3. ⭐ hold 72ч — КЛЮЧ к DD ≤ 20%!
hold 120ч (свинг) даёт MTM DD 55-64% — позиция 5 дней, цена уходит далеко,
потом возвращается и закрывается в плюс, но MTM показал −30-50%.
**hold 72ч** → позиция выходит раньше → незакрытая просадка мала → **DD 12-13%**!

| hold | ROI 2026 | MTM DD |
|:-----|:--------:|:------:|
| 12ч | +1070% | 15.7% |
| 24ч | +1124% | 15.9% |
| 48ч | +1194% | 15.5% |
| **72ч** | **+1350%** | **13.2%** 🏆 |
| 120ч | +1242% | 63.6% ❌ |

### 4. Кап eq для sizing (SIZING_EQ_CAP) — лоты не растут бесконечно
Без капа: eq→млрд → lots 2000+ → slippage убивает edge.
С капом: лоты от min(eq, cap) — риск фиксирован, DD стабилен.
