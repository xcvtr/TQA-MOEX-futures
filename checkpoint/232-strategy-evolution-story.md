# Эволюция стратегии: хроника с ошибками и проверками

**Дата**: 2026-08-16/17
**Источник**: checkpoint/232-dayofweek-audit-clean.md (все UPDATE 1-17)
**Цель документа**: показать другому человеку, как «успешные» стратегии
оказывались артефактами — и какие проверки это вскрывали.

---

## Контекст (откуда начали)

Проект — торговые стратегии на MOEX-фьючерсах (ClickHouse + tqa-framework).
Перед сессией был найден **TZ-баг**: таблица `futoi` (открытый интерес) была
сдвинута на −5 часов относительно цен → сигналы «видели будущее».
Данные перезалиты, начался аудит всех стратегий на чистых данных.

**Правило проекта**: статистика феномена → бэктест через общий Backtester
фреймворка → проверка по годам (OOS) → только потом вывод.

---

## Хронология: заявление → проверка → разоблачение

### Этап 1. OI (открытый интерес) — 🔴 мёртв (до сессии)
- **Заявлено**: +4154% за 3 года, PF 3.85, WR 69%
- **Причина**: futoi сдвинут −5ч → сигнал использовал будущие цены (look-ahead)
- **Проверка**: чистые данные → ROI +232%, PF 1.32, WR 47.7%
- **Дотюнинг NG**: максимум CAGR 23% (PF 1.39) — слабый, потолок найден
- **Вердикт**: OI — не edge, остался только как слабый диверсификатор

### Этап 2. oi_dom (стакан подтверждает OI) — 🔴 мёртв
- **Заявлено (чекп.211)**: стакан снижает DD 35%→17.5%, TATN +81%
- **Проверка сравнением цен**: TZ стакана корректен, но масштаб цен ×10 (не влияет на imbalance)
- **Честный тест (чистые TZ)**: OI+стакан даёт +1.8% за 9 мес ≈ 2%/год — не tradeable
- **Баг найден**: deals_qsh мультиконтрактный (5-8 контрактов на инструмент,
  `LIKE 'BR%'` смешивал цены ролл-гэпов) → фикс: активный контракт по max OI
- **Вердикт**: отброшен на всех тикерах

### Этап 3. Вспышки объёма (алгоритм Олега из 2021-22) — 🔴 мёртв
- **Гипотеза**: 5-сек вспышки z>8 (юрики-манипуляторы) подтверждают OI
- **Проверка 1**: deals_qsh (7 мес данных) — SI +86% / RN +54%, но 76-98% прибыли из июля 2026 → режимный
- **Проверка 2 (правильная таблица)**: moex.dom (12 млрд строк, 2024-26) —
  WR растёт с порогом (z≥20 → 82-91%!), НО только в 2025 году
- **Контроль**: случайные бакеты 48% vs вспышки 90% — эффект был, но один год
- **Вердикт**: режимный артефакт (трендовый 2025), не edge

### Этап 4. dayofweek 5 ног — 🔴 ОТОЗВАНО (selection bias)
- **Заявлено**: «5 ног (SBRF+SPYF+MM+GZ+RN) = +5942% при DD 18.4%!»
- **Как нашлось**: отсканировал 24 комбинации (12 тикеров × Пн/Чт), выбрал 3 лучшие
- **Проверка (Бонферрони)**: из 24 комбинаций ~1.2 ложных ожидаемы случайно;
  значим только MM (z=3.4), остальные — шум
- **Проверка OOS**: MM train z=3.4 → test z=1.1 — развалился
- **Вердикт**: «+5942%» = компаунд-разгон слабого сигнала + выбор лучших из 24

### Этап 5. SPYF+MM «значимый портфель» — 🔴 ИЛЛЮЗИЯ
- **Заявлено**: z=4.2 (Бонферрони прошёл, OOS держится, бутстрэп p<0.01)
- **Проверка вопроса «откуда MM?»**: прогнал SPYF ОТДЕЛЬНО
- **Результат**: SPYF-only = **+28% за 4 года, WR 50.6% = монетка** (шум!)
- **Вся прибыль портфеля +3042% — от MM** (94-99% PnL)
- **MM**: найдена сканом (selection bias), не прошла OOS, 2025 убыточен,
  вся прибыль из 2026 (обвал меди −65%) = ловля волатильности
- **Вердикт**: портфельный z=4.2 был иллюзией — одна нога тянула весь портфель

### Этап 6. «Опционная экспирация» (причина паттерна) — 🔴 тоже артефакт
- **Заявлено**: паттерн сильнее в недели 3-й пятницы (гамма-хеджирование ММ),
  avg ×3-8 в эти недели — «механизм подтверждён»
- **Проверка**: фильтр expiry_only в бэктесте → N падает в 4.3×, ROI +74% vs +2935%
- **sizing-буст score 1.5**: +3042% DD 20.3% — «работает»
- **НО**: всё это на MM-данных. SPYF-only = шум → «опционная экспирация» —
  артефакт MM-2026, не механизм
- **Вердикт**: отозвано вместе с Этапом 5

### Прочие отброшенные ранее (до сессии, для полноты)
- **Dragon / Impulse Return / Stop Hunt**: чемпионы +3000K → после фикса бага
  backtester (позиции не закрывались) → −39% / −88% / −125% — отброшены
- **IR Si**: +2884% — артефакт (6 уникальных дней за 4 года, экстремумы рубля)
- **MOEX-div**: закрыт (не edge)

## Классификация ошибок (что было не так)

| # | Тип ошибки | Пример | Как ловить |
|:-:|:--|:--|:--|
| 1 | **Look-ahead** (будущие данные в сигнале) | futoi −5ч; close Пт текущей недели для сигнала в Пн | WR>70% → подозрение; юнит-тест функции |
| 2 | **Selection bias** (выбор лучших из N тестов) | 5 ног: выбрал 3 из 24 | Бонферрони (z>3.1 при 24), OOS |
| 3 | **Режимность** (один год/месяц тянет всё) | MM 94% из 2026; SI из июля | разбивка PnL по годам; порог >80% из 1 периода = отклонить |
| 4 | **Портфельная маскировка** (одна нога тянет) | SPYF+MM z=4.2, SPYF-only = шум | КАЖДУЮ ногу отдельно в бэктесте |
| 5 | **Статистика ≠ бэктест** | WR 80% на D1 (close-to-close) vs 58% в бэктесте с trailing | всегда гонять через Backtester |
| 6 | **Компаунд-разгон** | +3377% без капа vs ~+500-1000% с капом 2M | показывать с капом как live |
| 7 | **Грязные данные** | мультиконтрактность, TZ-сдвиги, масштаб цен ×10/×100/×200 | аудит данных до анализа |

## Главные уроки

1. **Портфельный z-скop — не доказательство edge.** SPYF+MM z=4.2 выглядел
   идеально (Бонферрони, OOS, бутстрэп) — но SPYF отдельно = монетка.
   Проверка каждой ноги отдельно в бэктесте — обязательна.

2. **«Нашёл edge» после скана N комбинаций = подгонка.** Если стратегия
   найдена перебором, а не гипотезой — нужна поправка на множественное
   тестирование (Бонферрони) и подтверждение на данных, которых не видел.

3. **Красивая причина ≠ подтверждённый механизм.** «Опционная экспирация»
   звучала убедительно и даже усиливала цифры — но это был MM-2026,
   а не рынок. Механизм нужно доказывать на ноге, которая сама по себе edge.

4. **Режимность — главный убийца бэктестов.** Один волатильный год (обвал
   меди 2026) может сделать убыточную стратегию «прибыльной». Всегда:
   PnL по годам, доля лучшего года, контроль случайными сигналами.

5. **Скепсис — первый шаг, а не последний.** Каждое заявление проходило
   проверку только после вопроса пользователя. Теперь скепсис встроен
   в RULES.md проекта (раздел 7) — атаковать свои цифры ДО показа.

`skepticism-before-report`) — теперь любой «успех» проверяется 8 пунктами
до показа пользователю.
